# 🏧 ATM Simulator

Um simulador de caixa eletrônico desenvolvido para navegador, com o objetivo de praticar conceitos de desenvolvimento web utilizando HTML, CSS e JavaScript.

## 📌 Sobre o projeto

O **ATM Simulator** é um projeto que simula as funcionalidades básicas de um caixa eletrônico diretamente no navegador. A aplicação permite que o usuário interaja com uma interface para realizar operações bancárias simuladas.

Este projeto foi desenvolvido com fins educacionais, visando aprimorar conhecimentos em lógica de programação e desenvolvimento web.

## 🚀 Funcionalidades

- [x] Consultar saldo
- [x] Realizar saques
- [x] Realizar depósitos
- [ ] Simular transferências
- [ ] Exibir histórico de transações
- [ ] Validar valores e entradas do usuário
- [x] Exibir mensagens de sucesso e erro

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização e layout.
- **JavaScript** — lógica e interatividade.

## 🎯 Objetivos de aprendizagem

- Praticar HTML semântico.
- Desenvolver interfaces com CSS.
- Manipular elementos HTML com JavaScript.
- Trabalhar com eventos utilizando `addEventListener()`.
- Aplicar condicionais, funções e variáveis.
- Implementar validações e operações matemáticas.
- Manipular o DOM para atualizar informações na tela.

## 🔒 Aviso

Este projeto é apenas uma simulação educacional. Não realiza operações bancárias reais e não deve ser utilizado para armazenar dados financeiros ou informações sensíveis.
